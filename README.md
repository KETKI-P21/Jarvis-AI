# Jarvis AI Assistant 🤖

A Python-based personal AI assistant powered by Ollama and Llama 3.2.

## Features

- Answers questions using local AI.
- Uses Ollama to generate responses.
- Speaks answers using text-to-speech.
- Displays current date and time.
- Simple command-line interface.

## Technologies Used

- Python
- Ollama
- Llama 3.2
- Requests
- pyttsx3
- DateTime

## Installation

1. Install Python.
2. Install Ollama.
3. Download the Llama 3.2 model:

   ollama pull llama3.2:1b

4. Install dependencies:

   pip install -r requirements.txt

5. Run the assistant:

   python main.py
